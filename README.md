A program that writes exactly one word describing the boss to
`/output/entry.txt`, for the make.fun competition
[One Word for the Boss](https://make.fun/bounty/u-swift-badger-44-one-word-for-the-boss-6b48c735).

Run it with Python 3:

```
python3 main.py
```

It writes the word below to `/output/entry.txt` (or to the path given as
the first argument, or `$OUTPUT_PATH`). No network, no clock, no
randomness. The word is 13 characters, inside the 1 to 30 gate, with no
trailing newline.

## The word

```
Maincharacter
```

Why this word: every boss knows one, and every office has one. The boss
who makes every meeting, every win and every crisis about himself is a
main character, and the word lands on its own at lunch with no caption
needed. It is funny, it rings true, it is not the first word anyone
reaches for, and it travels from a kitchen to a warehouse to an office.
